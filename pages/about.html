QUICKTAG LAZYMOD

Features

Your essential tools are available directly on the page where you tag.

Tagging and palettes

Choose tags from groups and subcategories, use Flat view, and add or remove the entire visible set with one button. Palettes are saved locally in your browser.

Fuzzy search · Type-to-Tag

Find tags even with typos in the search box, or start typing when a page text field is not focused. Use the arrow keys to highlight a result, Enter to add it, and Escape to clear search.

Import, export, and editing

Import and export JSON palettes, edit them in the editor or in the more readable easyJson mode, and remove palettes you no longer need. Settings also let you back up or restore your full QuickTag configuration. The built-in starter palette is protected.

WD14 image analysis

Connect the extension to local ComfyUI to send an image to ComfyUI-WD14-Tagger. Progress is displayed as it runs, and detected tags can be added individually or all at once. Set the confidence threshold and exclusions in Settings.

Site profiles

Set selectors for the tag input, image, and source link on the current page. The element picker highlights the element under the pointer. Profiles can also be edited as JSON.

A customizable interface

Move and resize the window, dock it to an edge, collapse it to a bar, or hide it behind an edge handle. Ghost mode can be toggled or enabled only while holding its button or shortcut. Docked or floating mode, visibility, and position are remembered per site. Choose a built-in theme or set a custom accent color in Settings; each theme has its own palette and visual character, and your appearance choice is saved. New sites show only a handle at the right edge by default.

Quick actions

Copy your tags, clear the tag field, and keep track of the count. Click a tag to add or remove it; button states stay in sync with the tag field.

LOCAL IMAGE ANALYSIS

Install ComfyUI with comfy-cli

ComfyUI runs on your computer. The extension connects to the local server at http://127.0.0.1:8188 .

01

Install prerequisites

Install Python 3 and Git. Then open PowerShell in the folder where you want to keep your ComfyUI environment.

If the python command is unavailable, use py instead.

02

Install comfy-cli and ComfyUI

These commands create a virtual environment, install the CLI, and then download ComfyUI and ComfyUI-Manager.

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install comfy-cli
comfy install

If PowerShell blocks environment activation, you can skip activation and run pip through .\.venv\Scripts\python.exe -m pip ... .

03

Start ComfyUI

Start the server with CORS enabled and leave the terminal open while tagging.

comfy launch -- --listen 127.0.0.1 --port 8188 --disable-auto-launch --lowvram --enable-cors-header

The --enable-cors-header flag is required to allow QuickTag to connect without receiving a 403 Forbidden error.

04

Open in your browser

Once the server starts up, open your web browser and navigate to http://127.0.0.1:8188 if it doesn't open automatically.

TAGGING NODE

Install ComfyUI-WD14-Tagger

WD14 Tagger is an additional ComfyUI node. Install it once; any missing models will be downloaded automatically on first use.

  1. Use ComfyUI-Manager (Recommended) In ComfyUI, select Menu → Extensions and search for “WD14 Tagger” or “ComfyUI-WD14-Tagger” by pythongosssss. After installation, stop the server (press Ctrl + C in your terminal) and launch it again with the CORS command: 
    comfy launch -- --listen 127.0.0.1 --port 8188 --disable-auto-launch --lowvram --enable-cors-header
  2. Or install it manually In a terminal, navigate to ComfyUI\custom_nodes and clone the repository: 
    git clone https://github.com/pythongosssss/ComfyUI-WD14-Tagger.git
  3. Install dependencies and restart In the WD14 folder, run python -m pip install -r requirements.txt . If comfy-cli created a .venv environment in the ComfyUI root folder, use its Python interpreter: 
    ..\..\.venv\Scripts\python.exe -m pip install -r requirements.txt
    In either case, install dependencies in the Python environment used by ComfyUI. Then restart ComfyUI.
  4. Run an analysis in QuickTag Open a page with an image, click “Analyze image”, and wait for it to finish. Results appear in AI Suggestions.

Troubleshooting

QuickTag cannot connect to ComfyUI

Make sure ComfyUI is running and available at http://127.0.0.1:8188 . Keep the server terminal open.

WD14 node not found

Make sure ComfyUI-WD14-Tagger is in ComfyUI\custom_nodes , install its dependencies into the ComfyUI environment, and restart ComfyUI.

The analysis returns too many or too few tags

Change the confidence threshold in Settings → AI Suggestions. Run the image analysis again to fetch an updated result set. Blacklisted tags are hidden.

Cannot set an element selector

Pick an element of the appropriate type: a text field for the tag input, an image, or a source link/text field. Press Escape to cancel picking.
